Short: One board for every project

Dashboard now opens a compact cross-project Kanban with project swimlanes, project-scoped New Task actions, and same-project drag-and-drop. Project boards fit their working columns to the available width, show Questions as amber Needs input cards inside Agent Working, reveal AI Review only while occupied, and keep PR Review visible as the external-review queue. The workspace board keeps Completed in view and leaves Cancelled history on each project's board.
