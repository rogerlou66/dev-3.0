Short: One board for every project

Dashboard now opens a compact cross-project Kanban with project swimlanes, a tab-bar search, project-scoped New Task actions that appear instantly after creation, and same-project drag-and-drop. Project boards fit their working columns to the available width, show Questions as amber Needs input cards inside Agent Working, reveal AI Review only while occupied, and keep PR Review visible as the external-review queue. The workspace board keeps Completed in view with the two newest tasks per project and a Show more disclosure for older history, while leaving Cancelled history on each project's board.
