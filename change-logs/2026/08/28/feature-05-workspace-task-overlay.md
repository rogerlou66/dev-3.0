Short: Open agents over workspace board

Click an active task on Dashboard Board to open its full coding workspace in a focused overlay, then click the Kanban shadow, close it, or choose Global Kanban to return to the exact same board position. A fixed Inbox uses a counter-clockwise vertical rail and keeps questions plus Your Review tasks visible while compact 52px swimlanes scroll below it; AI Review remains a distinct occupied-only column, Done becomes a clickable count that restores completed cards, and inactive projects collapse without losing New Task. Hovering shows the complete title and latest update instead of an unreadably tiny terminal preview. On desktop, drag project handles aligned with each project name to prioritize whole swimlanes while Operations stays pinned; project names are the sole project-open controls. Todo and archived tasks keep their existing detail flow, while project boards retain the configured split or fullscreen behavior.
