Short: Android tablet client

Adds the Android tablet client with QR or link connection, the complete remote dev3 workspace in portrait or landscape, native task and project prompt input, notifications, streamed artifact saving, external handoffs, computer-side open actions, and secure session revocation. Connected workspaces no longer lose a full top row to host status: wide tablets use a zero-layout compact connection control, while narrow windows reuse the existing More sheet. Prompt typing stays outside the WebView and ambiguous delivery never clears or auto-retries the draft.
