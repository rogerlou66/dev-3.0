Short: Run any agent on any provider

Register the providers you pay for in the new **API models** section of Global Settings, ask them what they offer, give the models you want your own names, then bind those names to an agent's own roles in its preset — Claude Code's Opus/Sonnet/Haiku slots, Codex's main/subagent/review models. A pinned proxy sidecar bundled with the app resolves the names, so one Claude Code session can run its main model on OpenAI and its subagents on DeepSeek through OpenRouter. Upstream keys never leave your machine: the agent only ever sees a local proxy key, and a launch is blocked with the offending role named rather than silently falling back to the wrong model. The proxy is infrastructure rather than something you operate: dev3 brings it up with the app on one fixed loopback port and keeps that address across restarts, so running sessions survive a catalog edit. Presets saved in Settings now reach every open board and launch picker immediately, instead of only after the window reloads, and the launcher's first column is labelled **Harness**, because Claude, Codex and Gemini are agent CLIs rather than providers. A hand-built Codex preset now reaches the dev3 CLI as well: dev3 supplies its own permissions preset and profile when the preset itself decides nothing, instead of leaving the agent alive but unable to move the task's status. The Model field captions a routed preset with who serves it (`DS-Flash · OpenRouter`), the providers table says plainly that a subscription is not an API key, and the proxy now ships on every platform dev3 releases rather than Apple Silicon alone. The preset editor's drag handle and up/down arrows are gone: the handle never worked and the arrows permuted an order the grouped list does not show. Codex no longer opens a routed session complaining that it has never heard of the model: dev3 hands it generated metadata for every catalog model, which also restores `apply_patch` and parallel tool calls that its placeholder metadata switched off, and a role left unbound now follows the main model instead of a slug the proxy cannot serve.
